MAPLEROYALS FOR MAC — EXPERIMENTAL PREVIEW

You do not need Terminal, Python, Xcode, Command Line Tools, Homebrew or CrossOver.
Use an Apple silicon Mac running macOS 14–27. Only an M1 Pro has been gameplay-tested.
Keep about 10 GB free for the runtime, downloads and game; this is a practical budget.

FIRST TIME
1. Unzip the folder and move MapleRoyals.app into Applications (or a folder you keep).
2. Download the Windows WZ installer from https://royals.ms/downloads.
   Keep it as an .exe. You do not need the IMG installer.
3. Open MapleRoyals.app. If needed, click Enable Rosetta, complete Apple's prompt,
   and click Check again.
4. Click Choose game installer, select the WZ .exe, then click Install & Play.
   The app downloads and checks about 260 MB of support files.
5. Complete the Windows installer, keeping C:\MapleRoyals as the destination.
   Complete included Visual C++ installer prompts. Turn OFF Launch MapleRoyals
   in the installer before clicking Finish. Our app will start the game.
6. Sign in with your own account. Start at 800x600 for the smoother tested result.

NEXT TIME
Open MapleRoyals.app. It starts the installed game automatically.
Keep the launcher open while playing. Close the game before quitting the launcher.
The launcher does not yet support a second simultaneous client.

OPTIONAL FULLSCREEN WITH SIDE BARS
The Optional fullscreen folder includes two ready-built helpers. Use the 60 Hz
helper first; the 120 Hz version is intended for a compatible ProMotion MacBook Pro.
Close the game, open one helper, click Test, then Keep within 20 seconds.
Keep the helper open, open the game, and use Option+Return if needed.
After playing, close the game and use Restore normal display or quit the helper.
This temporarily affects the whole built-in screen. It does not fix 1024x768 lag.
Do not run both display helpers together.

YOUR FILES
The game and downloaded runtime are saved in your account under:
~/Library/Application Support/MapleRoyalsLauncher
Moving the .app does not move or delete this game folder.
Your account and game assets are not included in the ZIP. No account data is uploaded
by this launcher. Normal game network connections still occur.

PREVIEW LIMITS
This hobby preview is locally signed without an Apple Developer ID and is not
notarized. No Apple Developer account is used.
If macOS blocks the first launch because the developer is unidentified or Apple
cannot check it, and you trust the person who gave you the unchanged app:
1. After attempting to open it, open System Settings > Privacy & Security.
2. Find the notice for this app and click Open Anyway, then confirm Open.
The Rosetta helper or fullscreen helper may need their own first-open approval.
Apple documents this per-app exception: https://support.apple.com/en-us/102445
Do not disable system security or ignore a malware/damaged-app warning.
Managed Macs can prevent these exceptions. The downloaded Wine runtime can also
encounter separate macOS permissions; send any unexpected warning to the maintainer.

The fresh installation flow has not yet been validated through gameplay on a second
Mac. The earlier M1 Pro installation worked at 800x600; 1024x768 still lagged.
Use Show log if something fails, and send the maintainer the error after reviewing
for private details. Never share your password or PIC.
