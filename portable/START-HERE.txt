MAPLEROYALS FOR MAC — VERSION 0.3.0

RETRYING A FAILED SETUP
The launcher starts the Windows desktop before opening the game installer
and adds detailed setup logging. This resolved the reported installer startup
failure on a second M1 Pro Mac.
Quit the old launcher and restart your Mac once to clear any stuck Wine processes.
Replace the old MapleRoyals.app with this one, choose the same WZ installer,
and click Install game. Keep your existing MapleRoyalsLauncher data folder.
Keep the normal Mac display while completing setup.
If it fails or no installer window appears after several minutes, click Show log
and send launcher.log privately to the maintainer. It may contain your Mac user
name and local file paths. Detailed logging applies to setup, not normal play.

ONE APP FOR THE GAME AND FULLSCREEN
Open MapleRoyals.app. Fullscreen controls are inside the launcher; no separate
display helper is needed. The controls share one page under three headings:
- Play: launch games and see open client cards.
- Resolution: apply a screen size/rate or restore your normal display.
- Settings: install downloaded game files, view logs and find game files.
Players do not need Terminal, Python, developer tools,
Homebrew, CrossOver or Sikarugir.

FIRST-TIME SETUP
1. Move MapleRoyals.app somewhere you intend to keep it, such as Applications.
2. Download the official Windows WZ installer from https://royals.ms/downloads.
   Leave it as an .exe. You do not need IMG for this setup.
3. Open the app. First-time setup is under Settings. If it asks for Rosetta, click Enable Rosetta, complete Apple's
   prompt yourself, then return and click Check again.
4. Click Choose WZ installer, select the WZ .exe, then Install game.
   Leave the app open while it downloads about 260 MB of support files.
5. Complete the Windows installer at C:\MapleRoyals, including Visual C++ prompts.
   Turn OFF Launch MapleRoyals in the installer before clicking Finish.
6. Wait for Ready, click Play, then sign in with your own account. Start with 800x600 for smoother performance.

Use an Apple Silicon Mac running macOS 14–27 with about 10 GB free for setup.
Gameplay testing used an M1 Pro on macOS 26.5.2 and 27.0. Installer startup
was also confirmed on a second M1 Pro running macOS 27.0.

ALREADY INSTALLED?
Close the game and quit the old launcher. Restore and quit any old fullscreen
helper too. Replace MapleRoyals.app with this version. Open it, use Resolution to choose your
screen size and click Change screen resolution if wanted, then return to Play. Your game
installation stays in place. Do not delete the data folder or reinstall the game.

UPDATING THE GAME FILES
When MapleRoyals requires a new full installer:
1. Close every game window, under Settings, click Install downloaded update.
2. If you have not downloaded the installer yet, click Open download page.
   In your browser, download the latest Windows WZ .exe from the official
   MapleRoyals website. Leave it as an .exe file.
3. Return to the launcher, click Choose WZ installer, and select the new file.
4. Click Run selected installer. Allow about 10 GB free for staging and a backup.
5. Finish the Windows installer at C:\MapleRoyals. Turn OFF Launch MapleRoyals
   before Finish. If a game opens, close it so the update can finish.
6. Wait for Game files installed, then click Play. The game will not auto-start.

Wine and launcher display preferences are reused. New game files are installed
separately before replacing the current installation. Back to launcher backs out
before starting; once the installer opens, cancel using its own Cancel button.
If installation fails, the previous installation is kept. An older client may
not connect to the updated server, so retry with the latest WZ installer.
Backups are in Settings > Game files > backups; incomplete attempts can remain in updates.
They use extra space and are not automatically deleted. Keep a backup until the
updated game works. No automatic version checking or installer downloading is
provided. After force-quitting during an update, restart the Mac before retrying.

PLAYING AND FULLSCREEN
1. Open MapleRoyals.app. All three groups are shown together. Resolution defaults
   to 800x600; opening the app does not change the screen or start the game.
2. For fullscreen, under Resolution choose 800x600 or 1024x768 and a rate, then click
   Change screen resolution. Use 120 Hz only with a compatible display.
3. A new display mode asks you to Keep resolution within 20 seconds. Cancel or
   wait to restore the screen. Keeping the resolution does NOT start the game.
4. Click Play in the Play section. Skip steps 2–3 to keep your normal
   Mac display. Play itself does not change the Mac screen resolution.
5. In the game, select the matching resolution. Use Option+Return if needed
   to hide its window borders. Use 800x600 in the game with the 800x600 display.
6. Keep the launcher open. Close each game normally when finished; the launcher
   restores your normal display after the last game client closes.

MORE THAN ONE CLIENT
Click Play for the first game. The button then becomes Open another client.
Click it again for each additional game window; the launcher has no client limit.
Sign into a different account in each game window. Use the same launcher for
all clients, rather than opening extra copies of MapleRoyals.app.
The launcher shows how many clients are open. Closing one leaves the others
running. A numbered card also appears for each open client; scroll down if
needed. Cards have no screenshots and need no Screen Recording permission.
Close every game client before quitting the launcher. All clients
share the installed files, game settings, and Mac fullscreen display.
Each additional client uses more memory and graphics resources.
Two accounts were tested together on an M1 Pro running macOS 27.0, after retrying
the second client. If a client closes during login, click Open another client
to retry while leaving any working client open. This intermittent failure is
unresolved. More than two simultaneous game clients have not been tested.

You can change size/rate while playing: under Resolution choose the size/rate and click Change
screen resolution. This keeps the same game session; no restart is needed.
Set the game's own resolution separately to match.

Each opening selects 800x600 again. The refresh rate and confirmed display modes
are remembered, but nothing is applied until you click Change screen resolution.
You can restore the screen before playing with Restore normal display, or by
quitting the idle launcher.

Fullscreen scaling changes the WHOLE Mac desktop while playing. Restore normal
display in the launcher can undo it early. It does not fix 1024x768 graphics lag.
Startup has sometimes taken about 90 seconds after a macOS upgrade.

IF MACOS BLOCKS FIRST OPEN
This hobby app uses no Apple Developer account and is not notarized. If macOS
says the developer is unidentified or Apple cannot check the app, and you trust
this unchanged app from the repository, try opening once, then go to System
Settings > Privacy & Security > Open Anyway and confirm Open.
Do not disable security or override a malware/damaged-app warning.
Apple's instructions: https://support.apple.com/en-us/102445

DOWNLOADS AND SUPPORT
The repository includes the ready-built download/MapleRoyals-Mac.zip. A clone
or Code > Download ZIP includes that file; players do not build anything.
Download:
https://github.com/auslach/mapleroyals-mac/raw/refs/heads/main/download/MapleRoyals-Mac.zip
Full player guide:
https://github.com/auslach/mapleroyals-mac/blob/main/docs/PLAYER_GUIDE.md

Your game data stays at ~/Library/Application Support/MapleRoyalsLauncher.
The app ZIP contains no game assets, Wine runtime, used prefix or account data.
The app downloads its Wine runtime; get the official game separately.
Use Settings > Show log for errors. Review logs for private details before sharing. Never
share passwords or PIC. Forced-quit recovery and long-session
reliability remain unverified.
